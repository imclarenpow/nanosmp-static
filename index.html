Installing Fabric

  1. Download the Fabric installer from fabricmc.net.
  2. Run the installer, select the matching Minecraft version, and leave it pointed at your default install location.
  3. Open the Minecraft launcher — a new "fabric-loader" profile will appear.
  4. Download the recommended mods above from Modrinth, matched to the same Minecraft and Fabric version.
  5. Place the mod files in your .minecraft/mods folder.
  6. Launch using the fabric-loader profile and join the server.
